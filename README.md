# www.saintadrianmeats.com

Static stand-in for the current WordPress site (GoDaddy-hosted, "Yummy" theme). The business is closed and the site is in hibernation, so the goal is to reproduce what is shown today with as little as possible and cancel the WordPress subscription without losing the web presence.

## Images

All images are hotlinked from `https://saintadrianmeats.com/wp-content/...` (logo, favicon, contact banner, footer background, the three This Old Farm logos). Fonts come from Google Fonts.

**Before cancelling the GoDaddy subscription, every image URL must be moved somewhere else and updated here.** Otherwise they all break at once.

## Dropped from the WordPress site

Search box, back-to-top button, TrustedSite badge, emoji loader, Simple Download Monitor plugin, `wp-json`/feed/xmlrpc endpoints, all JavaScript.
